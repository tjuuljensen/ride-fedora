# V2 outcomes requiring an explicit replacement or decision

These records explain replacements and explicit dispositions for source
outcomes whose v2 functions were incomplete, obsolete, or had no current
Fedora package path. They do not delete or alter the legacy source. Reopen a
decision if its stated review trigger occurs.

| Source outcome | Decision and evidence | Review trigger |
| --- | --- | --- |
| `server:action.ViewIPaddress` | Retired as an install outcome, 2026-10-30. The `network-devices` v2 function only prints IPv4 addresses found by `ip addr show`; it does not establish desired state. The generic server source and consumers remain owned by `network-devices`. Operators can use `ip addr show` directly; a future read-only v3 status view would be a separate feature. | A request for IP discovery in the v3 CLI or a cross-repository ownership change. |
| `workstation:package.TecmintMonitorSh` | **Capability kept by owner; migrated to supported Fedora operation `package.glances`.** The v2 pair downloads an unverified HTTP script into `/usr/local/bin`. Fedora 44 publishes the signed `glances` RPM; upstream provides a local terminal monitor and bounded stdout metrics. The operation does not enable Glances' web service or claim exact parity with the one-shot script. It is selected through `fedora-workstation-glances`. | Fedora 44 Workstation lifecycle and restore passed; H095 tracks exact output and scope comparison before adding Web UI or Server service behavior. |
| `workstation:package.Galleta` | **Capability kept by owner; v3.0 path implemented as candidate `package.galleta`.** The v2 pair only printed links. Debian still packages Galleta 1.0+20040505-12; its 2003-2004 parser code declares BSD-3-Clause ([package details](https://packages.debian.org/trixie/amd64/galleta/download), [source and license](https://sources.debian.org/src/galleta/1.0%2B20040505-12/debian/copyright/)). The candidate verifies the Debian package SHA-256, extracts only the x86_64 CLI and copyright notice to the invoking user's local paths, and refuses to remove changed files. Plaso remains a partial path for modern WebCache ESE; it does not replace the standalone legacy parser. | Complete the declared Fedora 44 Workstation lifecycle. H099 tracks representative standalone IE cookie fixtures, output accuracy, and unsupported format boundaries. |
| `workstation:package.Xplico` | **Capability kept by owner; replaced for v3.0 by opt-in `package.zeek-core`.** `InstallXplico` prints a project URL and `RemoveXplico` prints an empty line; neither changes machine state. [Upstream lists Fedora packages only through Fedora 29](https://www.xplico.org/download). Fedora 44 offers a signed [Zeek Core RPM](https://packages.fedoraproject.org/pkgs/zeek/zeek-core/index.html/); official Zeek docs support offline PCAP processing and file extraction through its File Analysis Framework. Zeek's supported protocols and decoded outputs differ from Xplico, so the replacement preserves packet-analysis and file-extraction workflows without claiming full parity. The package is selected through `fedora-workstation-zeek`. | H098 tracks representative authorized PCAP extraction evidence and the protocol-decoder coverage still required by the owner. Reopen sooner if a real fixture identifies a required missing output or Fedora removes the package. |
| `workstation:setting.AtomTelemetry` | Retired, 2026-10-30. The two v2 functions edit `.atom/init.coffee`; the enable path starts and kills Atom, then deletes that file. [Atom's upstream repository](https://github.com/atom/atom) is archived and read-only. Applying this setting to a current Fedora 44 machine would edit a user's legacy file without an owned, maintained application or safe inverse. | A maintained Atom-compatible editor with the same telemetry contract, explicit user demand, and tested user-file backup and restoration. |
| `workstation:setting.Screensaver` | **Decision deferred by owner.** `DisableScreensaver` sets GNOME idle activation and lock to false and idle delay to zero. The same active v2 preset later calls `EnableScreenSaver`, so this earlier action is overwritten. | Decide whether an explicit lock-disabled value belongs in the kept configurable lock policy; require session-safety review and atomic prior-state recovery. |
| `workstation:setting.ScreenSaver` | **Decision deferred by owner.** `EnableScreenSaver` sets two GNOME lock booleans and idle delay 300 seconds, but v2 has no exact inverse or journal for the three settings. | Determine whether the kept configurable lock-timing operation covers this outcome; require baseline capture, partial-failure rollback, and disposable-session evidence. |

Reviewer: Codex. Glances, Zeek, and Galleta remain opt-in. Their Fedora 44
Workstation package lifecycles passed. Zeek's offline-PCAP CLI smoke and
Galleta's parser fixture accuracy remain separate v3.1 checks under H098 and
H099.
